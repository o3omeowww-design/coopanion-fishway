# fishway · 给只会待在一块屏上的桌宠开一条鱼道

把 **Coopanion 桌宠**（Cortico 桌宠）的窗口搬到另一块显示器上，**不改它一个字节**。

桌宠窗口永远只盖住一块屏，所以她走不出那块屏。这个脚本用 Win32 的 `SetWindowPos`
搬那个窗口——搬完她还以为自己在家，只是家换到了左边那块屏。

```
.\fishway.ps1 -Next          # 往右搬一块屏
.\fishway.ps1 -To 1          # 直接搬到最左边那块（从 1 数起）
.\fishway.ps1 -List          # 只看现在的显示器布局和她被关在哪块屏
```

---

## 怎么用

**要求**：Windows 10/11，PowerShell 5.1 或 7，不需要管理员权限。Coopanion 正常开着。

```powershell
# 1. 先看一眼布局，确认能认出桌宠窗口
.\fishway.ps1 -List

# 2. 搬
.\fishway.ps1 -Next
```

输出长这样：

```
displays:
  1: (-1920,182) 1920x1080   work area (-1920,182) 1920x1032
  2: (0,0) 2560x1440   work area (0,0) 2560x1380   <== pet is here
  3: (2560,157) 1920x1080   work area (2560,157) 1920x1032
pet window: 0x405B6   (0,0) 2560x1437
moved to display 3.
```

参数：

| 参数 | 作用 |
|---|---|
| `-To <n>` | 搬到第 n 块屏，**从最左边数起**为 1 |
| `-Next` / `-Prev` | 往右 / 往左搬一块；到头了就不动 |
| `-List` | 只打印显示器布局和她现在的位置 |
| `-DryRun` | 说会搬去哪，但不动手 |
| `-Title <片断>` | 找窗口用的标题片断，默认 `Cortico`（改名或换了宿主时用） |

想做成快捷方式/热键，随便找个宏工具调用 `powershell -File fishway.ps1 -Next` 就行。

## 她在新屏上站得住吗

站得住，实测过：她在 2 号屏走到最右 → `-Next` → 窗口落到 3 号屏 → 她从 3 号屏左边走出来站好。

搬完之后**页面的坐标系不会自己更新**，`pet_move_to` 之类的 0–1 相对位置是按窗口宽度算的。
窗口比屏幕宽的时候（见下面「接缝」），5% 和 95% 落在屏幕里的位置会略微偏——能走就够用。

---

## 接缝：一个解不掉的毛病

**窗口能平移，改不了尺寸。**

Coopanion 的桌宠窗口是 Electron 的 `resizable: false` 无边框窗口
（实测 `GWL_STYLE = 0x14000000`，没有 `WS_THICKFRAME`）。对着它调 `SetWindowPos`
改尺寸，函数返回 `True`，窗口一个像素都不动。

后果：三块屏 DPI 不一样时（我这台：左 100%、中 125%、右 100%），窗口被 Windows
按 **DIP 尺寸**钉在原来那一档，物理尺寸跟着缩放：

- 从 125% 的主屏搬到 100% 的屏：窗口从 2560×1437 变成 **2048×1149**
- 那块屏只有 1920×1080，所以右边多出 128px、下边多出 69px，压在隔壁屏上

视觉上没问题（她的脚正好落在新屏任务栏上沿），但那多出来的一条透明窗口会吃掉隔壁屏的点击。
**对形状有洁癖的人会介意，所以写在这里。**

已知没法从外面解决。要真解决得改宿主（Coopanion 自己的 `place()` 只在显示器增删、
分辨率变化时跑）——那就不是"不改一个字节"了。

**另外**：三块 DPI 不同的屏要当成一块连续平面横跨，坑最深，这个 v0.1 不做。

---

## 它是怎么找到她的

按窗口标题找（默认含 `Cortico`），并且类名以 `Chrome_WidgetWin` 开头——Electron 的窗口都是这个类。
所以理论上任何 Electron 桌宠只要标题对得上都能搬，不只是 Coopanion。

进程本身设成 **per-monitor DPI aware**（`SetProcessDpiAwarenessContext(-4)`），
不然所有坐标都会被系统按进程 DPI 虚构成另一套数字，搬过去就偏。
